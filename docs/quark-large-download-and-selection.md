# 夸克大文件下载与批量选择验收

日期：2026-11-11。网盘插件版本：0.1.3。宿主与插件需要一起更新，选择工具栏由插件声明、宿主通用渲染，不依赖平台 ID 判断。

## 实际问题

用户手机剪贴板的新分享包含 17 个文件，共 3,202,879,305 字节。匿名列目录成功，但 372,510,310 字节和 416,367,195 字节文件的取链接口均返回 HTTP 400、业务码 23018；同分享的 8,089 字节小文件成功返回 HTTP 206，并读取到前 4,096 字节。按 YunX 的额外 query/body 参数对照，大文件仍为 23018。

因此这次失败是当前匿名下载方式受服务端大小限制。此前 7.3 MB 样例通过，不能代表大文件也能免登录下载。

登录页另有体验问题：原实现以移动 UA 打开根路径，没有加载进度和失败反馈，用户无法找到登录入口。现在改为官方 PC 网页入口和桌面浏览器 UA，按手机宽度初始化缩放，保留双指缩放，并增加进度条与主文档失败重试。实际识别到有效夸克登录 Cookie、点击完成保存后，原失败文件可以完整下载。

## 修改

### 通用选择工具栏

- 插件页面声明 `selectionControls: true`，显示已选数量、全选／取消全选、反选。工具栏宽度与页面内容对齐，数量变化时不整体左右移动。
- 动作声明 `requiresSelection: true`，空选时禁用下载。下载动作支持 `cancelMethod: cancelInput`。
- 候选项必须有非空有效 ID 和布尔型 `selected`；标题、图集展示、操作行和禁用项不计入选择或提交。
- 提交、计数、反选及勾选框共用有效选择集合，页面刷新不会提交已移除的旧项目。
- 中英日韩文案完整；360dp、两倍字号的工具栏回归通过。

```json
{
  "selectionControls": true,
  "items": [
    {"id": "file-1", "title": "示例文件", "selected": true}
  ],
  "actions": [
    {
      "id": "prepareDownloads",
      "label": "开始下载",
      "primary": true,
      "requiresSelection": true,
      "cancelMethod": "cancelInput"
    }
  ]
}
```

### 下载前检查与登录恢复

夸克在入队前对所选最大文件执行一次只读取链检查，不请求文件内容，不硬编码 50 MB 阈值，也不保存这次返回的签名 URL。

- 匿名超限时，直接显示登录入口，失败文件不加入队列；有账号仍受限则如实提示当前方式受限。
- 登录、密码修正和错误重试通过隐藏字段保留分享上下文与 `pendingSelection`。空集合仍是空选，不会变成全选。
- 登录后重新展示文件列表供确认，不自动下载全部文件。
- 空选不发预检请求；取消会关闭客户端并抑制迟到结果，避免取消后继续入队。
- 预检只覆盖所选最大文件，不保证其他文件不会发生个别权限、链接失效或网络错误；每个任务仍保留实际取链和错误处理。

Redmi K50 / Android 14，使用用户原有失败任务重试，没有重新创建该任务。
